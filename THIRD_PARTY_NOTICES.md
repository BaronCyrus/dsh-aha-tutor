## Fonts

The board's handwriting fonts in `assets/fonts/` are subsets converted to WOFF2 for web delivery inside the plugin, generated by `scripts/build-fonts.py`. Each license ships next to the files.

| Font | Use | License |
| --- | --- | --- |
| [LXGW WenKai GB](https://github.com/lxgw/LxgwWenkaiGB) 1.530 Regular, cut to GB 2312 and CJK punctuation | Chinese handwriting on the board | SIL OFL 1.1 (`assets/fonts/OFL-LXGWWenKaiGB.txt`); its additional permission keeps the name for web-delivery subsets |
| [Caveat](https://github.com/googlefonts/caveat) 400, Latin (via [@fontsource/caveat](https://fontsource.org/fonts/caveat) 5.3.0) | Latin letters and digits on the board | SIL OFL 1.1 (`assets/fonts/OFL-Caveat.txt`) |

DeepSeek Harness packages (`@deepseek-ai/*`) and React are provided by the DSH runtime and are not redistributed.

Artwork in `docs/assets/` and `icon.png` was created for this project with ChatGPT image generation. Sample courses in `samples/` were written for this project.
