# v1.0.0：开窍首个版本，DSH 里的 AI 私人老师

开窍 · AI 私人老师的第一个版本：说出想学的东西，老师先了解你、再为你做一门课，在手写黑板上边写边讲。

- **定制课程**：一句话或一份教材即可开始。老师先用几道选择题了解基础、目标和时间，再给出「单元 → 章 → 讲」的课程蓝图，可以手动改，也可以用一句话让它改；确认后生成整门课的练习和实战项目。
- **手写黑板课堂**：语音和字幕同步讲解，黑板上逐字写出要点、公式（KaTeX）、示意图、数据图表和小动画；可暂停、回放、变速，并记住上次学到的位置。
- **随堂小测与自适应**：关键处停下来考你一题并询问把握程度，按掌握度模型区别对待猜对、犹豫和自信答错；一讲学完后，自动为薄弱知识点加一节巩固课。
- **举手提问、换个讲法**：讲课中随时提问，老师在黑板上专门回答，讲完回到原来的进度；也可以要求用打比方、画图、举例、讲简单点或讲深一点重讲当前一步。
- **练习、闪卡与复习**：每讲配练习，简答题由 AI 按要点批改；闪卡和知识点按间隔重复安排复习，学习计划按每周时间、学习日和截止日期排课。
- **资料变课程**：支持 PDF、Word、PPT、Markdown、网页链接和图片（需识图模型），讲解与速查表引用原文页码，长文档可一键消化成结构、论点和术语表。
- **工作室**：讲个概念、陪我解题、画出来看看、速查表、笔记、闪卡组、测验和约两分钟的讲解短片；任何一讲都能导出带板书动画、字幕和水印的视频。
- **实战项目**：代码类项目一键生成项目文件夹和起始文件，并在 DSH 中打开会话；完成后提交，老师按评分标准逐项点评。
- **对话联动**：新增「开窍 · AI 私人老师」会话预设，在对话里也能上白板讲解、出互动小测、建课和做速查表；侧栏可以随时打开白板。
- **语音**：默认使用系统语音；可选 OpenAI 兼容接口、火山引擎（豆包语音）、MiniMax 和 Azure 语音，密钥只保存在 DSH 凭据库中并只在 Host 端使用。
- **课程包与示例课**：课程可以导出为课程包分享给别人，也可以导入；自带「简谐运动」「贝叶斯思维」两门示例课，不消耗额度即可体验完整课堂。
- **在插件内更新**：设置页可以检查新版本，并用 DSH 自带的 pnpm 安装精确版本；新版本发布不满 24 小时时显示「待更新」，不绕过 DSH 的发布冷却期。

验证：全部自动化测试、两份构建和发布包检查通过，CI 在 Ubuntu、macOS 和 Windows 上运行测试；在 DeepSeek Harness 0.2.1-rc.2 的独立 profile 中实测了插件页（图标与中文名称）、示例课导入、黑板课堂（手写、示意图、标注、动画、图表、随堂小测、续播）、设置页的系统语音，以及深色主题下的视频导出（图表、动画静态画面、字幕换行）。

在 DSH 插件管理中安装 **1.0.0**，然后完全退出并重新打开 DSH 加载插件。
