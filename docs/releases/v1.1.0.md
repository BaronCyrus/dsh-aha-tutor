# v1.1.0：新增「关于作者」页面

插件左侧导航新增「关于作者」，可以在这里找到作者、项目链接和赞赏码。

- **关于作者**：导航最下方新增「关于作者」页面，展示作者 BaronCyrus、一句话介绍、GitHub 仓库和问题反馈链接，以及微信赞赏码和支付宝收款码。赞赏码随插件一起打包，离线也能显示。
- **英文界面**：「我的画像」的英文名改为 My profile，避免和新页面混淆。

验证：全部 62 项自动化测试、两份构建和发布包检查通过，CI 在 Ubuntu、macOS 和 Windows 上通过；在 DeepSeek Harness 0.2.1-rc.2 的独立 profile 中检查了新页面在深色、浅色主题和窄窗口下的显示，缩小后的支付宝收款码仍能识别为同一链接。

在 DSH 插件管理中更新至 **1.1.0**，然后重新打开 DSH 加载新版。
