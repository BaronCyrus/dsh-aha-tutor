# v1.11.1：讲课时的函数图和滑块不再丢失

这一版修复用户反馈的问题：老师让「看图、拖动滑块」时，黑板上有时只有图没有滑块，有时图和滑块都没有。

- **函数图和滑块不再被丢掉**：
  - 滑块叫 r（利率）、θ（角度）时，原来会被当成保留字拒掉，用到它的曲线跟着画不出来，整张图就没了；叫 e（离心率）时会被当成自然常数，图还在但滑块没了。现在都能正常显示；
  - 滑块换了写法也会整张图丢失，比如用了别的字段名、把范围写成一组数、按名字列出、缺最小值或最大值、两端写反或相等，或者多出第 5 个滑块。现在都能识别，缺的范围按初始值补上；
  - 公式里混进的 LaTeX 写法（如 \frac{1}{x}、\sqrt{x}、e^{-x}）、方括号，以及 omega 和 ω 这类同一个希腊字母的不同写法，现在也能读懂。
- **小测卡片不再挡住滑块**：老师讲完弹出「小测一下」时，卡片会盖住黑板下方刚画好的图和滑块。现在黑板会自动上移，把图和滑块留在卡片上方，答题前可以先拖滑块看看。画布和分页两种板书视图都一样。
- **动画里的滑块不再被裁掉**：黑板栏较窄时，动画下方自带的滑块会被裁掉。现在动画框会按内容自动长高。
- **讲课提示更明确**：写明了滑块的格式和命名，并要求只有黑板上真有带滑块的函数图时，老师才让学生去拖。

验证：全部 230 项自动化测试、构建和发布包检查都已通过，CI 在 Ubuntu、Windows 和 macOS 上全部通过。以下内容在 DeepSeek Harness 0.2.1-rc.5 的独立 profile 中，用一份手工做的复现课程（复利对比、抛体、椭圆、带小测的振动曲线、带滑块的动画）验证过：
- 修复前第 1 步只剩标题、第 2 步的图整张消失、椭圆图没有滑块；修复后四张图都画出了曲线并带滑块；
- 「小测一下」弹出时滑块在卡片上方，卡片开着也能拖动，曲线随之变化；
- 动画框从 175px 自动长到 215px，下方的滑块完整可见；
- 浅色、深色、窄屏和分页视图都检查过；
- 用打好的 1.11.1 安装包在全新 profile 中安装后，插件和预设正常加载。

在 DSH 插件管理中更新至 **1.11.1**，然后重新打开 DSH 加载新版。
