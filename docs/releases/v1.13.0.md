# v1.13.0：按知识点出题，老师讲这题

这一版能针对单个知识点出题练习，任何一道批改过的题都能请老师在白板上从你的答案讲起，对话里的小测也会把你的作答交给老师逐题纠错。

- **练这个知识点**：
  - 课程「进度」页的每个知识点、顶部「下一步」的薄弱提示，以及一轮练习结束页的「掌握度变化」里，都能直接练这一个知识点；
  - 每组 5 道只考这个知识点的新题，按你现在的掌握程度出：薄弱时先出两道基础题，掌握以后出边界情况和综合题。之前答题暴露出的误区，会专门出题检验；
  - 不重复做过的题：这一讲的课后练习和课堂小测、单元测验、之前练过的组都会避开，换个说法、换个数字也不行；
  - 作答计入掌握度，答错的题进错题本，标为「知识点练习」。这些题也能用「这题有问题？」核对，复习时也会用到；
  - 一组题还没开始做时，再进来还是这一组；做过以后再进来就出新的一组，结束页的「再来一组」可以马上换。
- **讲这题**：
  - 课后练习、单元测验、复习、练错题、知识点练习和学习工具里的测验，每道题批改后都有「讲这题」，答错时更显眼；错题本里每道题旁边也有；
  - 老师在白板上从你的答案讲起：先说出你可能是怎么想的、错在哪里（答对的题讲清为什么对），再一步步讲正确做法，写下要记住的要点，最后留一道同类题让你当场做；
  - 白板盖在当前页上，关掉就回到原来那道题，这一轮练习不受影响。课程里的这道同类题像课堂小测一样计入掌握度，不进错题本；
  - 讲解同时存进「即时答疑」，之后还能打开，也能接着追问。
- **对话里的小测会把作答交给老师**：以前做完对话里的小测，发回去的只有对错符号和每道题的前 60 个字，老师看不到你错成什么样。现在每道题都附上你的答案、答错时的正确答案、简答题的参考答案和批改意见，跳过的题会写明，老师会逐题纠错。
- **顺带修复**：答错后显示的正确答案里有公式时，以前显示成 `$P(A\mid B)$` 这样的原文，现在会正常显示公式。

验证：全部 315 项自动化测试、构建和发布包检查都已通过，CI 在 Ubuntu、Windows 和 macOS 上全部通过。以下内容在 DeepSeek Harness 0.2.1-rc.5 的独立 profile 中用 DeepSeek-V4.1-Flash 验证过：
- 「练这个知识点」一组约 35 秒写好，5 道题由易到难，答案逐题核对无误；做过以后再练，新的一组和上一组没有重复；
- 课后练习、错题本和学习工具测验里的「讲这题」，都从答错的那个答案讲起，最后的同类题换了场景；同类题计入了掌握度，错题本没有多出条目；
- 对话小测提交后，老师看到了每道题的作答，指出两道错题错在同一处，并在白板上讲评；
- 练习页、讲解白板、进度页和错题本在浅色、深色和窄屏下都检查过；
- 用打好的 1.13.0 安装包在全新 profile 中安装后，插件和预设正常加载。

在 DSH 插件管理中更新至 **1.13.0**，然后重新打开 DSH 加载新版。
