# v1.15.0：即时答疑拍题就问，首页能直接拖进文档

这一版的即时答疑能直接粘贴或拖进题目的截图和照片来提问，不用先存进资料库，也可以只发图不打字；首页能直接拖进文件，「消化长文档」拖进来就开始消化；即时答疑的记录也能删除了。

- **即时答疑带图提问**：
  - 在即时答疑的输入框里直接粘贴（⌘V / Ctrl+V）或拖进题目的截图、照片，一次最多 4 张。以前图片要先通过「添加资料」上传到资料库，而且一定要打字才能提问；
  - 可以只发图不打字，老师按当前模式来：「陪我解题」解图里的题，「讲个概念」讲图里的内容，「画出来看看」把它画出来讲。只发图的记录用板书开头的标题命名，不会一排都叫同一个名字；
  - 追问时可以再附新图，老师先看新的，再结合这条答疑里之前的图，合起来最多 4 张；
  - 图跟着这条答疑走，不进资料库，删除这条记录时一起删掉。白板上方的图可以点开看大图，想留下的点「存进资料库」。粘贴了但一直没提问的图，一天后自动清掉；
  - PDF、Word、PPT 这类文档拖进来，还是存进资料库，作为这次提问的资料附上。从表格里复制的单元格这类同时带文字的内容，粘贴进来的还是文字。
- **老师能不能看到图**：
  - 「出课与讲课」的模型能看图（带 🖼）时，图直接交给老师。老师会先把读到的题目写在板上，读错了一眼就能看出来；
  - 只有「批改与问答」的模型能看图时，图一传上来就先读出里面的字，老师拿到的是这些字，看不到图形；
  - 两个模型都看不了图时，每张图上都会写明老师看不到，并说明到设置里怎么改。这时只发图不能提问；打了字的问题照常发出，只按文字回答。以前这种图会被悄悄附上，老师当作没有图来回答。
- **首页直接拖进文件**：
  - 首页的输入框能拖进文件和文件夹，也能粘贴图片，按当前模式处理；
  - 「定制一门课」把文件存进资料库，作为建课资料附上；
  - 「消化长文档」拖进一份文档就马上开始消化，拖进好几份时都存进资料库，再让你选消化哪一份。以前附了好几份资料时只消化第一份，其余的不提；
  - 「讲个概念」「陪我解题」「画出来看看」和即时答疑一样：图跟着问题走，其他文件存进资料库；「两分钟短片」不收文件，会提示先换个模式。
- **即时答疑的记录可以删除**：「历史记录」里每条右边的 ⋯ →「删除」，确认后删掉这条答疑的板书和附的图；还在写的回答会先停掉。

验证：全部 377 项自动化测试、构建和发布包检查都已通过，CI 在 Ubuntu、Windows 和 macOS 上全部通过。以下内容在 DeepSeek Harness 0.2.1-rc.5 的独立 profile 中验证过：
- 用 DeepSeek-V4.1-Flash 只发一张直角三角形的图、不打字（两条直角边的长度只标在图上）：老师先把题抄到板上，从图里读出 AC = 3、BC = 4，解出斜边 AB = 5；再贴一张新图并打字追问，老师先读新图，再结合上一题的三角形，两问都答对；
- 「出课与讲课」用看不了图的 DeepSeek-V4-Pro、「批改与问答」用 DeepSeek-V4.1-Flash 时，图一贴进来就读出了里面的字，图上的标记和说明都正常；
- 不调用模型的检查：两个模型都看不了图时图上的提示、只发图被拦下、打字提问照常发出；「存进资料库」、点开大图、删除记录后图和板书一起删掉；首页「消化长文档」拖进一份和两份文档、「陪我解题」里粘贴的图带到即时答疑提问、「两分钟短片」的提示、「定制一门课」里的图存进资料库；
- 即时答疑和首页在浅色、深色和窄屏下都检查过；
- 用打好的 1.15.0 安装包在全新 profile 中安装后，插件和预设正常加载。

在 DSH 插件管理中更新至 **1.15.0**，然后重新打开 DSH 加载新版。
