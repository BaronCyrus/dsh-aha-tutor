# v1.16.0：云端语音加上 DeepSeek 与阿里云 Token Plan

这一版的云端语音多了两个服务：DeepSeek 自己的语音合成，和阿里云 Token Plan 的语音模型；密钥仍然只保存在 DSH 的凭据库里，只在本机 Host 端使用。

- **DeepSeek 语音**：
  - 「设置 → 语音讲解 → 云端语音」的云端服务里，第一项就是 DeepSeek 语音，用的是 DeepSeek 2026 年 11 月 13 日随全家桶应用 API 一起开放的语音接口（`POST https://api.deepseek.com/v1/tools/tts`）；
  - 音色从列表里选：**海星**（女声，默认）或**暗潮**（男声）；语种按文本自动识别，不需要选；
  - 接口地址默认 `https://api.deepseek.com`，已经带着 `/v1` 的地址也能用；
  - DeepSeek 返回的是 24 kHz、16 位单声道的 PCM，Host 端把一段讲解按句切开的几段拼好后装进 WAV 再交给浏览器，所以课堂朗读、导出视频里的声音和本机缓存都和别的服务一样；一段讲解只缓存一个文件；
  - DeepSeek 语音不提供语速参数，用设置里的默认语速和课堂上的播放速度来调。
- **阿里云 Token Plan 语音**：
  - 云端语音里多了第五个服务「阿里云 Token Plan」，用它的 qwen-audio-3.0-tts-plus 模型朗读，默认音色 longanlingxin（女声），也可以填 longanlufeng（男声）；
  - Token Plan 回答的是一个音频链接，Host 只从阿里云、走 https、不带密钥去下载，绝不会把密钥发给下载地址；
  - 阿里云规定 Token Plan 仅限在 AI 编程和智能体工具中交互式使用，超出范围的调用可能导致订阅暂停或 API Key 被封禁，使用前请阅读订阅须知。感谢 moore-hemw 写的第一个版本（#1）。

验证：全部 379 项自动化测试、构建和发布包检查都已通过，CI 在 Ubuntu、Windows 和 macOS 上全部通过。以下内容在 DeepSeek Harness 0.2.2-rc.3 的独立 profile 中验证过：

- 用仓库链接安装后插件正常加载；「设置 → 云端语音」里第一项是 DeepSeek 语音，接口地址默认为 `https://api.deepseek.com`，音色可以在海星（女声）和暗潮（男声）之间选，选完刷新页面仍然保留；
- 没有保存 DeepSeek 密钥时点「试听」，请求确实走到 DeepSeek 的语音服务，并提示先保存密钥；
- 设置页在浅色、深色和 700px 窄窗口下都检查过；
- DeepSeek 的请求格式、PCM 合并、WAV 封装、按句切分和磁盘缓存，以及 Token Plan 的音频链接校验，都由自动化测试覆盖；这一版没有用账号密钥发起真实的语音合成，不消耗额度。

在 DSH 插件管理中更新至 **1.16.0**，然后重新打开 DSH 加载新版。
