# v1.17.1：板书和讲解对上拍

这一版修正了板书和讲解音画不同步的问题：课堂和导出视频里，板书现在都会在讲到对应那句话时才写出来，不再提前，也不再落后。

- **短句配图不再拖慢后面**：以前一步板书统一用一个书写速度，一句很短的话配上一张图，图会画到后面几句，后面的内容跟着晚好几秒。现在每句话的板书只用到下一句要写东西为止，板书落后于讲解时会加快补上。
- **云端语音不再抢跑**：以前云端语音的音频还没下载好，板书就开始写，而且只是按估算的语速往下走，常常比声音快一到三秒。现在等声音真正响起才开始写，之后按音频实际播放到的位置推进。
- **不再写了又擦**：系统语音开口晚时，板书以前会先写到后面，再退回去重写。现在会等语音开口（最多 3 秒），不会抢在语音前面，写出来的内容也不会再消失。
- **按发音时长估算句子**：以前按字数估算每句话的时长，一个英文单词会被当成好几个汉字那么长。现在按读出来要多久估算。
- **导出视频同样对上拍**：导出视频的板书和字幕改用与课堂相同的逐句计时，并按真实语音的长度拉伸；同一句话的字幕和板书一起出现。
- **示例课逐句同步**：两门示例课的每一项板书都标好了对应的句子，打开就能看到逐句书写。

验证：全部 390 项自动化测试、构建和发布包检查都已通过；新加的测试拿旧代码跑都会失败。以下内容在 DeepSeek Harness 0.2.2-rc.5 的独立 profile 中验证过，没有调用模型：

- 用系统语音播放示例课「简谐运动」第 1 讲，每项板书都在对应句子开口后 0～0.35 秒内出现，没有一项提前；
- 用本机模拟的云端语音（真实合成的音频，故意延迟 1.5 秒返回）播放示例课「贝叶斯思维」第 1 讲：音频响起前板书不动，每句的第一项板书与这句话在音频里实际开始的时间相差 −7～+96 毫秒；
- 导出了这一讲的视频（带语音和字幕），字幕与真实语音的句子边界相差约 50 毫秒，板书在本句字幕出现后 0.1～0.45 秒开始写；
- 检查了深色主题和 530～800px 的窄窗口；浅色主题没有检查。

在 DSH 插件管理中更新至 **1.17.1**，然后重新打开 DSH 加载新版。
