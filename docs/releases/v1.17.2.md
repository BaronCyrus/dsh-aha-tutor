# v1.17.2：公式都排版显示

这一版让学习者看到的公式都按数学公式排版显示，不再露出 LaTeX 源码或美元符号。

- **提示里的公式**：练习题的提示（💡）以前按纯文本显示，里面的公式会露出源码，例如 `$\omega = 2\pi / T$`。现在提示和题目一样排版公式。
- **图注和滑块名**：图下方的说明文字和函数图滑块的名称，现在和板书其他文字一样排版公式。
- **图里的文字**：示意图、图表和函数图里画不了排版公式，以前写在标注里的公式会露出美元符号。现在转成 ω₀、x²、√(k/m) 这样的普通字符显示，板书和导出视频都一样。
- **填空题判分**：以前标准答案如果写成 `$-kx$` 这样的公式，学习者输入 `-kx` 会被判错。现在判分时忽略美元符号。
- **老师写公式的规则**：以前只要求板书段落里的公式用 LaTeX，现在整块板书（标题、列表、表格、提示框、图注）和所有题目、选项、提示、解析都要求用 LaTeX。讲解要读出来，所以仍用口语说公式；图里的文字仍用普通字符；函数图的公式仍按计算器写法；填空题的标准答案仍是学习者能直接打出来的普通文字。

验证：全部 395 项自动化测试、构建和发布包检查都已通过。以下内容在 DeepSeek Harness 0.2.2-rc.5 的独立 profile 中验证过，没有调用模型：

- 打开一门用 DeepSeek 生成的课，练习提示里的 |F| = kx 正常排版，没有美元符号；
- 在这门课的板书里加入带公式的图注、滑块名、示意图标注和图表坐标轴：图注和滑块名正常排版，示意图、函数图和图表里的公式显示为普通字符，没有美元符号；
- 检查了深色主题、浅色主题和 560px 的窄窗口；
- 导出视频里的图注没有实际导出检查；改动后的出题和板书规则也没有用真实模型重新生成验证。
