# v1.2.0：手写板书、逐句同步和课堂侧栏

板书改用手写字体，并跟着讲解一句一句写，课堂里也多了侧栏；同时修复了网页导入、后台生成、长文档消化等问题。

- **手写板书**：板书改用霞鹜文楷（中文）和 Caveat（英文），随插件打包常用字子集（约 1.8 MB），用到哪部分字才加载哪部分，导出的视频也用同一字体；少见的字回退到系统楷体。**设置 → 板书字体**可以切回标准体。
- **逐句同步**：新生成的课会标出每项板书属于哪一句讲解，讲到那一句才写，正在讲的内容用荧光笔划出；字幕逐句显示并排版公式，朗读时公式读成自然的文字。旧课保持原来的节奏。
- **课堂侧栏**：显示本课要点和进度、讲过的内容（包括提问和换个讲法，点一下回到那一步）以及提问框，可以收起；窗口较窄时放在板书下方。
- **举手提问**：回答和换个讲法直接写在板书上，随课程保存，下次打开还在原处。
- **后台生成**：离开页面不再中断生成，课程蓝图、确认课程、板书、练习、速查表和资料消化都会在后台继续；等待较久时可以取消。
- **长文档**：资料消化分段读完整份文档再汇总，失败的部分会重试一次并在结果里注明，可以重新消化；设计课程用的资料摘要也覆盖整份文档。
- **网页导入**：拒绝本机和内网地址的各种写法，以及解析到内网地址的域名；每次跳转都重新检查，下载大小有上限；出错提示跟随界面语言。
- **确认课程更快**：确认时只准备项目和第一单元的练习，其他讲次的练习在第一次打开时生成；生成蓝图时会显示已经写好几课。
- **样例课**：《贝叶斯思维》第一节板书里的集合 {2, 4, 6} 改为按公式排版，不再显示多余的反斜杠。

验证：全部 78 项自动化测试、两份构建和发布包检查通过；在 DeepSeek Harness 0.2.1-rc.2 的独立 profile 中用 DeepSeek-V4.1-Flash 实际备课和上课，检查了手写字体分片加载、逐句高亮、侧栏提问和后台生成，以及深色、浅色主题和窄窗口下的显示；另用发布包安装（不是 link）确认字体能正常加载。

在 DSH 插件管理中更新至 **1.2.0**，然后重新打开 DSH 加载新版。
