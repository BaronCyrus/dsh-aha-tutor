# v1.3.0：写出过程、课程规模和练习结算

随堂检查可以写出完整过程，写错时老师在黑板上订正；建课时能选课程规模，看着大纲一步步生成；练习做完有结算和下一步建议。同时修复了推理模型把板书和短片截断的问题。

- **写出过程**：有计算或推导的一讲，会请你一步一行写出过程，公式实时预览。老师找出第一处写错的地方，在黑板上订正后再接着讲，订正会留在这一讲里。
- **课程规模**：建课问卷新增「课程规模」：让老师决定、精简（3–8 讲）、标准（10–20 讲）或完整（25–45 讲）。生成蓝图时能看到进行到哪一步，大纲一个单元一个单元地出现。
- **蓝图编辑**：
  - 用一句话修改时，先列出新增、删除、改名和调整的讲，应用后才生效；
  - 可以让老师把一讲拆成两讲，或讲深一些；
  - 删除单元、章或已经开始学的讲之前会先确认；
  - 开课后，也能在课程页「⋯ → 编辑课程大纲」里加讲、加单元，或让老师续写一个单元，已有的进度保留。
- **练习**：
  - 题目可以带示意图；
  - 做完一组会显示星级、正确率、最长连对和各知识点的掌握变化，并给出下一步建议；
  - 答题时显示连对；
  - 支持键盘作答：1–4 选择，Enter 提交或继续，H 看提示。
- **课程页**：知识点按未开始、薄弱、学习中、熟练、掌握五级显示，没学过的不再亮一格。顶部的「下一步」依次建议该复习的、最薄弱的知识点和下一讲。「开始复习」只复习这门课。
- **推理模型**：DeepSeek 等推理模型思考时会用掉输出额度，导致板书和讲解短片被截断，或报 EMPTY_RESPONSE。现在写板书时使用较低的思考强度，所有调用都按思考强度留足额度，额度用光时会自动加额度重试；课堂里的报错改为中文。
- **学习计划**：学习计划和首页的今日安排改用「课程图标 + 简短课程名」标注，不再重复完整课程名。

验证：全部 89 项自动化测试、两份构建和发布包检查都已通过。在 DeepSeek Harness 0.2.1-rc.2 的独立 profile 中，用 DeepSeek-V4.1-Flash 实测了以下内容：
- 写出过程与板书订正；
- 按精简规模建课，大纲逐步出现；
- 修改建议、拆分一讲，以及开课后续写单元；
- 键盘作答与练习结算；
- 课程页的下一步建议；
- 深色、浅色主题和窄窗口下的显示。

讲解短片在修复前会被截断，修复后能完整生成。

在 DSH 插件管理中更新至 **1.3.0**，然后重新打开 DSH 加载新版。
