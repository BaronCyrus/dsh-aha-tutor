# v1.4.0：联网备课、学习月历、板书导出和更快开讲

建课前可以先联网查资料；学习计划变成能打勾的月历；板书能导出成 PDF 和图片；打开新的一讲从要等半分钟以上缩短到一两秒，等得久时还能看到老师在做什么。同时修复了云端语音、公式显示和朗读、窄屏布局等一批问题。

- **联网查资料**：新建课程时，老师可以先用 DSH 的网页搜索查一查这个主题，出题和设计蓝图都会参考查到的内容，课程页的「参考来源」里能点开原网页。首页的「🌐 联网查资料」默认打开，附了资料时默认关闭；DSH 没法搜索时照常建课，并说明原因。
- **学习计划月历**：
  - 学习计划页改成月历，点某一天就能看到当天的安排，过去的日子保留当时的安排和完成情况；
  - 学完一讲、做完复习会自动打勾，今天和之前的事项也可以在计划页或首页手动勾上、取消；
  - 手动勾掉的讲算作学完，后面的日子会重新安排；今天已经学过的时间会从今天的安排里扣掉。
- **板书导出**：课堂和讲解短片顶部的「导出板书」可以导出：
  - PDF：一页放一页板书；
  - PNG 图片：每页一张，多页打包成 ZIP；
  - Markdown 文本：和原来一样。

  导出的板书保留手写字体、公式、荧光笔、圈画和课上的提问，外观跟随设置里的白板外观。
- **开讲更快**：备课、提前备课、换个讲法、即时答疑和讲解短片不再先等模型思考：能关掉推理的模型（如 DeepSeek）直接关掉，其他模型用最轻的一档。用 DeepSeek-V4.1-Flash 实测，三讲新课打开后 1–2 秒开讲，原来要 25–77 秒，板书结构不变。
- **备课进度**：备课超过 3 秒时，黑板中间显示老师在做什么：正在构思，或正在写第几步，这一步的小标题边写边出现，并显示已用时间。讲到一半追上老师时，显示老师正在写的那一步。
- **云端语音**：
  - 选了云端语音后，打开课堂不再整页空白；设置里的「测试」会说明出了什么问题；
  - 语音出错时，控制栏上方会写明原因，课堂继续无声进行；「重试」恢复语音并重讲这一步，「设置」直达语音设置。
- **公式**：
  - 插件内置的 KaTeX 改为和 DSH 样式表同一版本（0.18.7），上标、下标恢复正常字号，≠ 等叠加符号不再错位；
  - 太长的行间公式会先缩小，再在 =、+、→ 后换行，不再被栏宽截断；公式编号不再盖住公式；
  - 朗读和导出的视频按公式的意思读，不再读出 LaTeX 命令名。
- **窄屏**：即时答疑和讲解短片在窄窗口里整页滚动，课堂保持完整高度，不再被追问框挤压。
- **出错不再整页空白**：某个页面出错时，原来整个插件页会变成空白，重新打开还会回到出错的那一页。现在出错的页面会显示提示，并提供「重试」和「回到首页」，左侧导航照常可用，下次打开从首页开始。对话里的板书标签和工具卡片出错时，只在出错的部分显示提示和「重试」。
- **其他修复**：
  - 板书还没写完时也能「换个讲法」；
  - 所有报错都有中文和英文说法；
  - 图形里的虚线画完后保持虚线；
  - 带等号的高亮（如 `==乘积 = 0==`）能正常显示。

验证：全部 121 项自动化测试、两份构建和发布包检查都已通过。在 DeepSeek Harness 0.2.1-rc.2 的独立 profile 中验证了以下内容：
- 用 DeepSeek-V4.1-Flash 实测：联网查资料后建课、备课进度，以及关掉思考后的开讲速度；
- 学习计划月历的自动和手动打勾，板书导出的 PDF（用 macOS 的 PDFKit 打开校验）、PNG 和 ZIP；
- 用本地模拟服务测试了云端语音出错时的提示和恢复；
- 页面出错时的提示、「重试」和「回到首页」；
- 用打好的 1.4.0 安装包在全新 profile 中安装后，示例课的课堂、板书导出和学习计划在浅色、深色和窄窗口下都显示正常。

在 DSH 插件管理中更新至 **1.4.0**，然后重新打开 DSH 加载新版。
