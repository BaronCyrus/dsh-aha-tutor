# v1.5.0：无限画布和语音提问

黑板变成一张能拖动、缩放的画布，整讲的板书一页接一页排在上面，讲课时镜头跟着老师走；提问也可以直接说出来，用 DSH 的语音输入在本机识别。

- **无限画布**：
  - 整讲的板书从上到下排在一张画布上：拖动或滚动来移动，按住 Ctrl/⌘ 滚动、双指捏合或点 −、+ 来缩放（5%–300%）；
  - 双击某一页放大到这一页，点「全貌」看所有页，点百分比回到 100%；
  - 讲课时镜头跟着老师写的地方走；自己一拖动或缩放就停止跟随，点「回到老师这里」再接上；
  - 习惯一次看一页的话，在「设置 → 板书视图」里选「分页」。导出的 PDF、PNG 和视频不受影响。
- **语音提问**：
  - 课堂的提问框和即时答疑旁边有了麦克风：点一下开始说，再点一下停止，识别出的文字填进输入框，检查后再提问；说话时课堂自动暂停，一次最多录 2 分钟；
  - 识别用的是 DSH 的实验功能「语音输入」（本机 SenseVoice，语言跟随它的设置），录音不上传，插件也不保存；
  - 第一次用之前，要在 DSH 的插件管理里启用「语音输入」，并在它的详情里「下载并准备」模型（约 240 MB）。没准备好时麦克风是灰的，点它会提示还差哪一步。

验证：全部 129 项自动化测试、两份构建和发布包检查都已通过，CI 在 Ubuntu、Windows 和 macOS 上全部通过。在 DeepSeek Harness 0.2.1-rc.2 的独立 profile 中验证了以下内容：
- 启用语音输入并下载 SenseVoice 模型后，用合成的中文提问作为麦克风输入，走完录音、识别、填入提问框；未启用和模型未准备时的提示；
- 画布的镜头跟随、拖动、滚动、缩放、双击放大一页、全貌和「回到老师这里」，以及切换到分页视图；
- 浅色、深色和窄窗口下的课堂、即时答疑和设置页；
- 用打好的 1.5.0 安装包在全新 profile 中安装后，课堂和画布显示正常。

在 DSH 插件管理中更新至 **1.5.0**，然后重新打开 DSH 加载新版。
