# v1.6.0：讲错了能核对，曲线按公式画

觉得老师讲错了、题目的答案有问题，都可以请老师先想清楚再核对，真错了就当场改正，连存档一起改好；由公式画的曲线改成按公式逐点计算，还能拖动滑块看它怎么变。这一版也修好了几处语音问题。

- **这一步不对？**：
  - 课堂控制栏和讲解记录的每一行都能发起核对，可以写一句或说一句哪里不对，也可以不填；
  - 老师先开着思考核对（算数、推导、事实、单位和随堂小测的答案），通常要几秒到半分钟，然后在黑板上回答：确实错了，就框出错处、写出正确内容，并把这一讲的存档一起改好，改过的地方标着「✎ 已更正」，鼠标停在上面能看到原文，导出的 PDF 和 PNG 也保留这个标记；没错，就针对你的疑问讲清楚为什么；
  - 核对不影响掌握度。课程的每一讲、即时答疑、讲解短片和对话里的白板都能用。
- **练习和测验题核对**：
  - 练习、单元测验、学习工具里的测验和复习题判分后，可以点「这题有问题？」，请老师核对题目、答案和判分；
  - 题目真有错，就地改正并标「✎ 已更正」，再按改好的题重新判这次作答，掌握度和复习安排按「当初就判对了」重新计算；
  - 核对时可以接着做下一题，结果出来后页面顶部会提示。
- **精确函数图**：
  - 板书新增函数图：y = f(x)、参数方程和极坐标曲线都由插件按公式逐点算出，不会画歪；坐标轴按课本的样子画，三角函数按 π/2 标刻度；
  - 可以标点，画虚线参考线、阴影面积和切线；公式里的参数（最多 4 个）变成滑块，拖动时课堂自动暂停，导出和视频按默认值画成静态图；
  - 练习题也能用函数图配图；「简谐运动」示例课的振动曲线换成了带振幅、角频率滑块的函数图。
- **语音修复**：
  - 云端语音服务卡住时，约 10 秒内就会发现并给出提示，不再白等 45 秒；
  - 语音提问的麦克风跟随 DSH「语音输入」里选中的设备；
  - 换了云端音色后，试听和重播立刻用新音色；合成过的语音真正缓存在本机，重播不再计费；窄窗口里麦克风旁的提示不再被裁掉。

验证：全部 165 项自动化测试、两份构建和发布包检查都已通过，CI 在 Ubuntu、Windows 和 macOS 上全部通过。在 DeepSeek Harness 0.2.1-rc.2 的独立 profile 中验证了以下内容：
- 用 DeepSeek-V4.1-Flash 核对课堂：故意写错的算式被找出、在黑板上更正并改好存档；正确的步骤得到解释；从讲解记录质疑前面的步骤时，回答出现在当前位置；
- 练习、单元测验、学习工具测验和复习题的核对：答案有误、表述有歧义、简答题判分复核和本来就对的情况；
- 用本机模拟的语音服务测试卡住、发到一半中断和慢速返回；麦克风使用 DSH 里选中的设备；
- 函数图的滑块，浅色、深色和窄窗口下的课堂与练习页，以及导出的 PNG；
- 用打好的 1.6.0 安装包在全新 profile 中安装后，课堂、函数图和核对入口显示正常。

在 DSH 插件管理中更新至 **1.6.0**，然后重新打开 DSH 加载新版。
