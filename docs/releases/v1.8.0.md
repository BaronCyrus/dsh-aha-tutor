# v1.8.0：扫描件和照片也能读出文字

这一版让扫描版 PDF、照片和全是图片的文档也能当资料用：能看图的模型会把里面的字识别出来。同时修复了三个问题：DSH 0.2.1-rc.3 上插件显示「加载失败」，看老师订正后课堂卡住，以及多选题只能选一个。

- **扫描件和照片也能读**：
  - 下面这些资料里的字，都会交给你在开窍设置里选的、能看图的模型识别（设置里带 🖼 的模型，比如 DeepSeek-V4.1-Flash）：
    - PDF 里没有文字层的页（扫描页、整页图片）；
    - 几乎全是图片的 Word；
    - 只有图片的幻灯片；
    - 直接上传的照片；
  - 上传时会显示「正在识别图片里的文字 3/12」，可以随时取消；一次识别 3 页，一个文件最多识别 200 页；
  - 识别出的文字保留页码，建课、速查表、闪卡、测验、资料库搜索和讲课引用都和普通资料一样用；
  - 有页没识别出来、超过 200 页没有识别，或者当前模型看不了图时，资料下方会写明是哪些页、为什么；整份都是扫描件而模型看不了图时，会提示该换哪个模型。
- **修复「加载失败」**：DSH 0.2.1-rc.3 新增了一项必填设置，插件卡片因此显示「加载失败」，对话里的「开窍 · AI 私人老师」也用不了。现在补上了这项设置，旧版 DSH 照常加载。
- **修复看老师订正后课堂卡住**：写过程的小测答错、点「看老师订正」后，老师讲一句就停下，按钮却一直显示在播放，要先暂停再播放才能继续。现在订正会讲完并接着上课；系统语音偶尔没有反应时，课也不会卡住。
- **修复多选题只能选一个**：有的题干写着「多选」，却只能选一个答案。现在这类题都按多选处理，多选题上方还会提示「多选题：选出所有正确的选项。」

验证：全部 199 项自动化测试、构建和发布包检查都已通过，CI 在 Ubuntu、Windows 和 macOS 上全部通过。以下内容在 DeepSeek Harness 0.2.1-rc.3 的独立 profile 中验证过：
- 「开窍 · AI 私人老师」预设正常加载，可以选用；
- 用 DeepSeek-V4.1-Flash 测试：
  - 写过程的小测答错后点「看老师订正」，订正的每一句都正常朗读，讲完自动回到正课，中途没有停；
  - 黑白扫描的 PDF 两页都识别准确，公式写成了 LaTeX；12 页的扫描件几秒就读完，中途取消不会留下资料；
  - 照片里的字也识别出来了，资料卡片上出现了建课和学习工具的按钮；
  - 用识别出的资料生成测验，多选题按多选出题，可以同时选中多个选项；
- 资料库里的识别进度和提示，在浅色、深色和窄窗口下显示正常；
- 用打好的 1.8.0 安装包在全新 profile 中安装后，插件和预设正常加载。

在 DSH 插件管理中更新至 **1.8.0**，然后重新打开 DSH 加载新版。
