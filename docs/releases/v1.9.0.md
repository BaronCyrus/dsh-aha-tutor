# v1.9.0：字更大，导航可以收起

这一版回应了「字太小，要凑近屏幕才看得清」的反馈：开窍里的文字默认大了一档，设置里还能再调大；左侧导航可以自己收起或展开，上课时还会自动收起，给白板让出地方。

- **字默认更大**：
  - 正文从 14px 调到 15px，提示文字从 12.5px 调到 13.5px；
  - 练习题的题干改成 16px、选项 15px，都用正文颜色，不再是浅灰色的小字；
  - 闪卡的字放大到 22px，答案很长时卡片会自动变高，不会溢出。
- **新增「文字大小」设置**：在 **设置 → 文字大小** 里选**标准**、**大**或**特大**，开窍里的文字一起变大，马上生效。DSH 的「设置 → 通用设置 → 字号大小」也会让开窍的文字跟着变。白板和思维导图仍用它们自己的缩放按钮。
- **左侧导航可以收起**：
  - 导航最下面的**收起**把它收成一列图标，点 **»** 再展开，开窍会记住你的选择；
  - 收起后，鼠标放到图标上，或用键盘 Tab 选中，旁边马上显示名称；
  - 以前窗口不够宽时导航会自动只剩图标，现在默认显示文字；
  - 上课时（课堂、即时答疑、讲解短片）导航自动收成图标，离开后恢复你的选择；窗口窄到手机宽度时也只显示图标。这两种情况下点 **»** 会临时展开、盖在页面上，选好页面、点旁边空白处或按 Esc 就收回。
- **顺带修复**：
  - 对话旁的白板标签页里，文字整体发灰，讲解记录也不换行；
  - 速查表里的条目不跟随速查表自己的字号设置，打印出来是灰色；
  - 手机宽度下，课程卡片会把页面往右撑出一截。

验证：全部 211 项自动化测试、构建和发布包检查都已通过，CI 在 Ubuntu、Windows 和 macOS 上全部通过。以下内容在 DeepSeek Harness 0.2.1-rc.3 的独立 profile 中验证过：
- 练习题、闪卡和设置页在三档文字大小下显示正常，浅色、深色和手机宽度都检查过；
- 把 DSH 的字号大小调到 18 后，开窍的文字跟着变大；
- 导航的收起、展开，以及悬停和键盘选中时显示名称都正常；窗口很窄时临时展开，选好页面后自动收回，按 Esc 也能关闭；
- 上课时导航自动收起，课堂用宽版布局（讲解记录在白板右侧）；离开课堂后导航恢复展开；
- 用打好的 1.9.0 安装包在全新 profile 中安装后，插件和预设正常加载。

在 DSH 插件管理中更新至 **1.9.0**，然后重新打开 DSH 加载新版。
